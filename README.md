# 散散味儿（去 AI 味）

一个中文写作 skill：按目的、位置、立场处理文字，删掉维护读者关系的句子，补上支撑论证的内容。

它不靠换同义词，也不靠加口语。它先确认文字要对什么负责，再按这个标准修改。

## 适用

- 文字读着空，读完说不出作者的主张。
- 文字像 AI：结构完整、句子顺畅，却没有支撑论证的内容。
- 文字过度防御：大量“不承诺”“不代表”“不保证”，正面主张很少。
- 需要把口语化的草稿改成书面、平实、简洁的文字。
- 需要从零写一段文字，先确认事情、读者和立场，再动笔。

## 安装

放到 DeepSeek Harness 的 skills 目录，目录名用 `sansanweier`：

```bash
git clone https://github.com/Xtopia5616/sansanweier.skill.git ~/.dsh/skills/sansanweier
```

Windows 下的目标路径是 `%USERPROFILE%\.dsh\skills\sansanweier`。也可以手动复制本目录到该位置。

其他支持 `SKILL.md` 的 agent，可以放到对应的 skills 目录。

## 使用

改一段文字：

```text
用 deai-zh 改下面这段，保留事实和数据：
[文字]
```

写一段文字：

```text
用 deai-zh 写一段项目说明，读者是评审，要让他们接受“这个方案可行”：
[材料]
```

## 它怎么工作

1. 写之前确认三件事：这段文字处理什么事，目标受众是谁，作者是否认同。
2. 写的时候先定全文论证，再写各节；正面主张占主要篇幅。
3. 改的时候按六项判断：服务对象、段落推进、立场代价、句子移用、否定句篇幅、术语。
4. 最后看篇幅分配：主要篇幅用于说明事情、给出判断、交代依据和承担代价，还是用于维护读者的感受、展示完整、预防批评。

语言要求：书面、平实、简洁；长句为主；动词用书面形式；术语用通行说法。

## 边界

事实、数字、日期、引文、来源、经历和结论以原文为准；否定、条件、范围、时间、完成状态和归因保持不变；“可能”与“确定”、“计划”与“已经”的区别保持原样。学术作业和署名文本由作者本人完成。
